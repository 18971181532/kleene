支持的语法

a z 0普通字面量
. 任意字符（s 标志下含换行）
[abc] [a-z] [^0-9]字符类 / 范围 / 取反
\d \w \s / \D \W \S数字 / 单词 / 空白及取反
* + ? {n} {n,} {n,m}量词，默认贪婪
*? +? ?? {n,m}?惰性（最短）量词
ab|cd交替，从左到右优先
(...)捕获组（submatch）
(?:...)非捕获组
^ $行首 / 行尾（m 标志逐行）
\b \B单词边界 / 非边界
\t \n \r \f \v \xHH \uHHHH转义字符

明确不支持

  • 反向引用 \1 … \9（与 RE2 一致，属于非正则语言，会显式报错）。
  • 对“可为空的子表达式”再次量词化（如 (a?)*）的零宽重复计数，与 Python re 的极端边界处理可能不同；引擎始终线性、不挂起。
  • Lookaround (?=…)、原子组、条件表达式暂不支持。
